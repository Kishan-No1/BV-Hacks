# Nod Implementation Plan

> **For agentic workers:** three builders implement workstreams A, B and C **in parallel in the same working tree**.
> Each builder owns a disjoint set of files (listed per workstream). Steps use checkbox (`- [ ]`) syntax.

**Goal:** a macOS 26+ menu-bar app that shows Claude Code progress in the notch and lets the user allow or deny
permission requests from there, with a plain-English risk read-out. Working live demo by end of day.

**Architecture:** Claude Code command hooks run `hooks/nod-hook.sh`, which POSTs the hook JSON to an HTTP server
inside Nod on `127.0.0.1:47474`. `NodCore` (no UI) decodes the payload, reduces it into an observable
`SessionStore`, scores permission requests with `RiskEngine`, and holds the HTTP response for a
`PermissionRequest` until the user answers in the island. The `Nod` app renders the store in a notch-pinned
`NSPanel` with SwiftUI.

**Tech stack:** Swift 6.4 toolchain, SwiftPM (tools 6.2, language mode 5 on every target), macOS 26 minimum,
SwiftUI + AppKit + Carbon hotkeys, Network.framework, swift-testing, bash + jq + curl.

**Sources of truth:** behavior `docs/superpowers/specs/2026-11-15-nod-design.md`; visuals
`docs/design/prototype.html`; hook wire format `docs/superpowers/plans/hook-contract.md`.

## Global rules

- Never read-modify-write the real `~/.claude/settings.json`. Scripts are tested with `--settings <temp file>` only.
- Never `git push`. Never bare `git stash`. Kill every background process you start.
- Fail open to Claude Code's **normal prompt**, never to "allow". The only auto-allow is an explicit user rule.
- Build with your own scratch path: `swift build --scratch-path .build/<task id>`.
- Tests never bind port 47474. Use port 0. Manual runs use `NOD_PORT` (B: 47481, C: 47482).
- Other builders edit the same tree. Write whole files that compile; do not leave half-edits on disk. If the build
  breaks in a file you do not own, wait a minute and retry. Do not fix it; report it if it persists.
- Commit only your own paths: `git add <paths> && git commit -m "..." -- <paths>`. Retry on `index.lock`. Never `git add -A`.

## Shared API (already compiled in the scaffold)

```swift
// Sources/NodCore/RiskEngine.swift  (A)
public struct RiskEngine: Sendable {
    public init()
    public func assess(toolName: String, toolInput: JSONValue, cwd: String) -> Assessment
}
// Sources/NodCore/StepFormatter.swift  (A)
public enum StepFormatter {
    public static func completed(toolName: String, toolInput: JSONValue, cwd: String) -> String
    public static func current(toolName: String, toolInput: JSONValue, cwd: String) -> String
    public static func toolLabel(toolName: String, toolInput: JSONValue, cwd: String) -> String
    public static func promptHeadline(_ prompt: String, limit: Int = 60) -> String
}
// Sources/NodCore/RulesStore.swift  (A)
public final class RulesStore: @unchecked Sendable {
    public static var defaultFileURL: URL { get }
    public init(fileURL: URL?)
    public var rules: [Rule] { get }
    public func match(toolName: String, toolInput: JSONValue, cwd: String) -> Rule?
    public func suggestion(toolName: String, toolInput: JSONValue, cwd: String, assessment: Assessment) -> RuleSuggestion?
    @discardableResult public func add(_ rule: Rule) -> Rule
    public func remove(id: UUID)
    public func recordHit(id: UUID)
}
// Sources/NodCore/SessionStore.swift  (B)
@MainActor @Observable public final class SessionStore {
    public private(set) var sessions: [Session]
    public private(set) var pending: [PendingRequest]
    public private(set) var autoAllowedCount: Int
    public private(set) var toast: Toast?
    public var selectedSessionID: String?
    public init(riskEngine: RiskEngine = RiskEngine(), rules: RulesStore? = nil, now: @escaping () -> Date = Date.init)
    public var currentRequest: PendingRequest? { get }
    public var activeSession: Session? { get }
    public var isAnyWorking: Bool { get }
    public func session(id: String) -> Session?
    public func ingest(_ event: HookEvent)
    public func requestDecision(for event: HookEvent, timeout: TimeInterval = 580) async -> Decision?
    public func resolve(_ id: PendingRequest.ID, _ decision: Decision, remember: Bool = false)
    public func dismiss(_ id: PendingRequest.ID)
    public nonisolated func hookHandler(permissionTimeout: TimeInterval = 580) -> HookServer.Handler
}
// Sources/NodCore/HookServer.swift  (B)
public final class HookServer: @unchecked Sendable {
    public typealias Handler = @Sendable (HookEvent) async -> HookResponse
    public static let defaultPort: UInt16  // 47474
    public init(port: UInt16 = HookServer.defaultPort, handler: @escaping Handler)
    public var port: UInt16? { get }
    @discardableResult public func start() async throws -> UInt16
    public func stop()
}
```

App wiring (C): `let rules = RulesStore(fileURL: RulesStore.defaultFileURL)`, `let store = SessionStore(rules: rules)`,
`let server = HookServer(port: port, handler: store.hookHandler())`, `try await server.start()`.

Text convention: `Assessment.title`, `Step.text` and `Session.currentStep` may contain `` `backtick` `` spans. The UI
renders them in monospace (the prototype's `<code>`).

## Workstream A: core-logic

**Verify:** `swift test --scratch-path .build/core-logic --filter NodCoreTests`

- [ ] **A1 RiskEngine, test first.** `Tests/NodCoreTests/RiskEngineTests.swift`, then `Sources/NodCore/RiskEngine.swift`
  (helpers in `Sources/NodCore/Risk/`). Rules:
  - Read-only tools (`Read`, `Grep`, `Glob`, `LS`, `WebSearch`, `TodoWrite`, `NotebookRead`) → low, reason "Read-only".
    A read outside `cwd` → review, reason "Outside the project".
  - `Bash`: split the command on `&&`, `||`, `;`, `|` and newlines outside quotes; classify each segment; the result
    is the highest level. Read-only/test/build (`ls`, `cat`, `head`, `tail`, `grep`, `rg`, `find` without
    `-delete`/`-exec`, `pwd`, `echo` without redirect, `git status|diff|log|show|branch`, `npm test`, `npm run
    test|lint|build`, `pytest`, `swift build|test`, `cargo build|test|check`, `go build|test`, `make` with no
    target or `test|build`) → low. Installs and network (`npm install`, `pnpm|yarn add|install`, `pip install`,
    `brew`, `curl`/`wget` without a pipe, `git pull|fetch|clone`) → review. Destructive (`rm -r`/`-rf`/`-fr`,
    `git push --force`/`-f`, `git reset --hard`, `git clean -f`, `sudo`, `chmod -R`, `chown -R`, `curl|wget ... | sh|bash`,
    `dd`, `mkfs`, `> ~/.ssh/...`, writes to `.env*`) → high. Anything unknown → review.
  - Any path argument that resolves outside `cwd` raises the level one step (`RiskLevel.raised`) and adds
    "Outside the project". `/dev/null` is exempt. Resolve `~`, `..` and relative paths lexically, no disk access.
  - `Edit`, `Write`, `MultiEdit`, `NotebookEdit`: inside the repo → review with a `DiffPreview`. Outside the repo or a
    sensitive file (`.env*`, `~/.ssh/**`, `~/.claude/settings*`, `*.pem`, `*.key`, `id_rsa*`, keychains) → high.
  - `WebFetch` → review, "Fetch docs.example.com", reason "Network". MCP and unknown tools → review, "Use <tool>".
  - Titles: low Bash uses `tool_input.description` when present (it is Claude's own summary), else ``Run `npm test` ``.
    Review and high titles always come from Nod's templates, never from `description`: "Delete files outside this
    repo", "Force-push to origin", "Run a script from the internet", "Edit session.ts", "Write .env.local".
  - `Assessment.command` = the full command for Bash.
- [ ] **A2 DiffPreview.** From `old_string`/`new_string`: split by line, drop the common prefix and suffix lines,
  `removed`/`added` = remaining counts, `lines` = up to 3 removed then 3 added, each cut to 120 characters. `Write`:
  all lines added (first 4 shown). `MultiEdit` (`edits` array): sum the counts, preview the first edit.
- [ ] **A3 StepFormatter, test first.** `Read` → ``Read `src/auth/session.ts` `` (repo-relative; file name only when
  outside `cwd`). `Bash` → ``Ran `npm test -- src/auth` `` (command cut to 48 characters). `Edit`/`MultiEdit` →
  ``Edited `session.ts` ``. `Write` → ``Wrote `session.ts` ``. `Grep` → `Searched “SessionError”`. `Glob` →
  ``Listed `**/*.ts` ``. `WebFetch` → `Fetched docs.example.com`. `WebSearch` → `Searched the web for “…”`. `Agent`/`Task`
  → `Ran a subagent: <description>`. MCP → `Used <tool> (<server>)`. `current(...)` gives the present tense without
  backticks for file names: "Editing session.ts", "Reading session.ts", ``Running `npm test` ``.
- [ ] **A4 RulesStore, test first.** Repo identity = nearest ancestor of `cwd` containing `.git` (file or directory),
  else `cwd`; `match` and `suggestion` both use it. Prefix match on the whole command only when it has no shell
  operators (`;`, `&`, `|`, backtick, `$(`, `<`, `>`, newline). `suggestion`: nil for high risk, for commands with
  operators, and for sensitive paths; Bash prefix = the first two words when the second is a subcommand (`npm test`,
  `git status`, `swift build`), else the first word; never suggest a bare interpreter or `rm`, `sudo`, `curl`,
  `git push`. Edit tools: tool-wide rule with label "edits here". Persist atomically; a corrupt or missing file
  loads as empty. Tests use a temp directory and `fileURL: nil`.
- [ ] **A5** Assert the exact read-outs for every `permission-request-*` fixture (table in the task brief).

## Workstream B: bridge

**Verify:** `swift test --scratch-path .build/bridge --filter NodBridgeTests`

- [ ] **B1 HookServer, test first.** `Tests/NodBridgeTests/HookServerTests.swift` starts a real server on port 0 and
  talks to it with `URLSession`. `NWListener` bound to `127.0.0.1` only
  (`requiredLocalEndpoint = .hostPort(host: .ipv4(.loopback), port: ...)`, `allowLocalEndpointReuse = true`). Parse
  the request line, headers and `Content-Length` body (accumulate across `receive` calls; 1 MB cap); answer with
  `Connection: close`. Routes and status codes: `hook-contract.md` section 7. One `Task` per request; cancel it when
  the connection fails or closes before the response. `stop()` cancels the listener and every connection.
- [ ] **B2 SessionStore, test first.** The scaffold body works; pin it down with tests and fix what they find:
  FIFO order across sessions, timeout → nil, task cancellation → request removed, `PostToolUse` for the same call
  clears a held request, `Stop`/`UserPromptSubmit`/`SessionEnd` clear the session's requests, rules never auto-allow
  a high-risk call, `remember: true` stores the rule, pass-through tools, unknown session ids create sessions,
  status transitions, 200-step cap.
- [ ] **B3 `hooks/nod-hook.sh`.** Contract: `hook-contract.md` sections 4 and 7. `$1` = event name. Reads stdin,
  `curl -sS --connect-timeout 0.3 --max-time <1 or 590> -o <tmp> -w '%{http_code}'`. Prints the body only for
  `PermissionRequest` with status 200 and a non-empty body. Always `exit 0`. `NOD_PORT` overrides the port.
- [ ] **B4 `scripts/install-hooks.sh` / `uninstall-hooks.sh`.** `--settings PATH` (default `~/.claude/settings.json`),
  `--hook PATH`, `--dry-run`. jq merge, timestamped backup, idempotent, atomic write, refuses invalid JSON.
- [ ] **B5 `scripts/simulate.sh`.** `scripts/simulate.sh [--port N] <fixture>...` and `scripts/simulate.sh story`.
- [ ] **B6 Script tests** in `Tests/NodBridgeTests/HookScriptTests.swift` using `Process`: hook script against a live
  test server (allow, deny, 204, server down → empty stdout, exit 0, under 1 s); install twice = one entry per
  event; install keeps unrelated hooks; uninstall restores the original document; backup file exists.
